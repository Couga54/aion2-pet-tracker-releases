# Aion 2 Pet Tracker — downloads

A desktop tracker for the Aion 2 pet collection. It shows each pet's level and soul count, counts souls live while you farm, and keeps favorite pets in an overlay on top of the game.

## Download

**[Download the latest installer](https://github.com/Couga54/aion2-pet-tracker-releases/releases/latest/download/Aion2PetTracker-Setup.exe)** (Windows 10/11, x64)

All versions and change notes are on the [Releases](https://github.com/Couga54/aion2-pet-tracker-releases/releases) page.

- It installs for the current user, no administrator rights needed, and .NET is bundled.
- To count souls, install the free [Npcap](https://npcap.com/#download).
- Run the game in windowed or borderless mode.
- The installer is not code-signed yet, so Windows SmartScreen may warn about it. Click **More info → Run anyway**.

This repository only hosts release files; the source code is private.
